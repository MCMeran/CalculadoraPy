# 🧮 Sistema de Calificaciones

## 📘 Descripción
Este proyecto consiste en un programa desarrollado en **Python** que permite gestionar las calificaciones de varios estudiantes mediante el uso de arreglos (listas).  
El sistema realiza operaciones básicas como mostrar datos, calcular el promedio, identificar notas extremas y modificar valores.

## 🎯 Objetivo
Aplicar los conceptos fundamentales de arreglos o vectores en Python, utilizando índices, ciclos, condiciones y operaciones de cálculo para manipular datos de manera práctica.

## 💻 Lenguaje utilizado
- Python 3.8 o superior

## ⚙️ Funcionalidades desarrolladas
1. Mostrar todas las calificaciones.  
2. Mostrar una calificación específica por índice.  
3. Calcular el promedio general.  
4. Identificar la calificación más alta.  
5. Identificar la calificación más baja.  
6. Contar cuántos estudiantes aprobaron.  
7. Contar cuántos reprobaron.  
8. Modificar una calificación.  
9. Mostrar nuevamente el vector actualizado.

## 🚀 Instrucciones para ejecutar el programa
1. Guarda el archivo como `calificaciones.py`.  
2. Abre una terminal o consola.  
3. Ejecuta el programa con el comando:
   ```bash
   python calificaciones.py
